1　解压 & 启动

  • 解压 aiphotoarrange.3.x.x.portable.x64.zip 到本地硬盘（不要在 zip 内直接运行，不要放 U 盘）。
  • 双击 aiphotoarrange.exe 启动。首次被 SmartScreen 拦截点「更多信息 -> 仍要运行」；杀毒软件误报加白名单即可。

2　填两个 Key（必填，软件包无 Key 填充为 XXXXXXX）

Key去哪申请填在哪
高德 Key高德开放平台 注册个人 Key（免费，够用）参数配置「📍 地理位置」-> 高德 Key
大模型 Key见第 3 步，二选一参数配置「🤖 大模型服务」-> API Key

3　选大模型方案（二选一）

☁️ 在线 qwen3.7-plus（推荐，快）
服务商 dashscope / 模型 qwen3.7-plus。阿里云百炼 申请 Key。按量计费，约 2–4 元 / 1000 张。
🔒 本地 LM Studio（隐私最佳，免费，推荐本地方案）
服务商 lmstudio / 模型 qwen/qwen3.8-27b（Q4_K_M）。需显存 ≥ 32G，自装 LM Studio 并开启本地服务。照片不离开本机，质量优于旧版 gemma4。
⚠ 本地方案硬性约束　 【推荐 LM Studio + qwen3.8-27b】加载 qwen/qwen3.8-27b（Q4_K_M），服务端口设 21234，参数务必设：并发 6 · Max Draft = 4 · Draft possibility = 0 · 关闭 Unified KV Cache（必须关！开启会导致同一批照片每次结果不一致）。
【旧版 Ollama + gemma4】仍可用：Ollama 必须锁 v0.30.8（下载，tag 写作 v0.3.8），模型 gemma4:31b，但质量与速度均逊于 LM Studio 方案。其它预置服务商未完整测试。

4　填路径 & 参数

项说明
源文件夹待整理原始照片目录，支持多个（点「浏览」逐个添加，每个都递归扫描子目录）
归档目标输出目录，不能与源相同或互相包含。软件复制不删原图
常驻城市省/市二级下拉。家城市弱化日常地名，外地保留景点全名
提取档位A 精华档 ~20-40% 只要最精彩的 · B 纪念档 ~40-80% 有意义都留 · C 归类档 ~100% 只分类不删
并发数默认 6（本地 LM Studio 32G 显存上限；在线模型按服务商 QPS/TPM 限额调整，调大更快但可能被限流）。默认按天分线程，配置文件切 by_batch 则按批分线程。本地推理框架需在其设置中开启并发（LM Studio 设并发 6；Ollama 需开启并行，但注意 Ollama 不支持 qwen 系模型并发）
改完点 「💾 保存配置」。切档位后建议「全新跑 (--fresh)」按新档位全量重评；断点续跑在档位变化时会自动校验 02 进度指纹并作废重跑（旧文件归档不删），但会浪费几分钟重跑 01a/01b，所以切档位优先选全新跑。

5　开跑

  • 底部选运行模式 -> 点 ▶ 开始一键归档流水线。启动先预检大模型连通性（✅ 推理服务在线 才真正开跑）。运行期间软件自动阻止系统睡眠，晚上挂着跑无需改电源设置。
  • 全新跑（默认）：从头来过，按当前档位全量重评。第一次跑直接用这个，输出目录非空时自动改名旧目录避免混淆。
  • 断点续跑：中途被中断后接着跑，配置没变会跳过已完成的阶段直接续上。
  • 仅合并日报 (03a)：对已跑完 02 的归档目录单独补跑 03a 同日事件合并，无需改配置文件。
  • 仅跨年聚合 (03b)：对已跑完 02 的归档目录单独跑 03b 跨年主题聚合，把多年同主题事件（如生日庆祝）归到一起，无需改配置文件。
  • 中途可 ⏹ 停止，进度已保存，下次断点续跑接着来。

6　看结果

  • 结果在归档目标路径下，按 YYYY-MM-DD-事件名 自动建子文件夹，精华照片已复制进去。目录结构示例：2024-05-02-杭州西湖断桥漫游 / 2024-08-10-洪崖洞夜间漫游。原图不动，AI 命名偶有偏差（如 OCR 错字）直接改文件夹名即可。
  • 📱 手机端删除列表：处理完成后会在归档目标同级目录生成 non_highlight_photos_*.txt，记录所有非精华照片文件名与大小。通过微信文件传输助手发送到手机，用 PhotoCleaner APP 导入后可一键删除手机相册中的非精华照片，只保留精华。PhotoCleaner 现支持结果本地持久化（误触返回/重启自动恢复预览）与远程分析（手机直传缩略图到自建 PhotoArrangeAPI 服务、原图不出手机），详见《用户操作手册》§8.6。
  • 极少数处理失败的照片记在程序目录 02_unprocessed_photos_<Profile>.txt，原图仍在源目录。详细日志在 logs/（01a / 01b / 02 / 03a / 03b 各一份），反馈问题附上。
高级用户：GUI 不能新增 / 改名 Profile 和服务商，需直接编辑 pipeline_config.yaml（结构清晰有注释，空格缩进不用 Tab，改前备份）。新增 Profile 在 profiles: 段复制一段、改 key 和目录即可。Profile 只切换输入/输出目录和中间文件后缀，其余参数（城市、高德 Key、大模型服务、运行参数）全局共享。完整说明见《用户操作手册》。
